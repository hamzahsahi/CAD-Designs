# CAD Design Portfolio

A collection of electrical and mechanical CAD projects demonstrating experience with electrical schematic design, component documentation, and 3D enclosure modeling.

This repository currently includes a **120 VAC Motor Control Schematic** and a **custom electronics enclosure designed in Autodesk Fusion**.

## Projects

### 1. 120 VAC Motor Control Schematic

An electrical control schematic for a 120 VAC motor control system.

The design demonstrates the organization and documentation of a motor control circuit using standard electrical components and schematic conventions.

#### Key Features

- 120 VAC motor control circuit
- Start/stop control
- Motor control and switching components
- Electrical wiring and component connections
- Organized schematic layout
- Component identification and labeling
- Electrical design documentation

### 2. Autodesk Fusion Enclosure

A custom 3D enclosure designed in Autodesk Fusion for housing electronic components.

The project demonstrates mechanical CAD fundamentals and the process of translating component and packaging requirements into a physical enclosure design.

#### Key Features

- 3D enclosure modeling
- Component placement considerations
- Openings and clearances for external connections
- Dimension-based mechanical design
- Multi-feature CAD modeling
- Design intended for electronics packaging
